# Comment My Site

Расширение для Chrome: комментарии к любой странице, как в Figma. Ставите маркер на нужное
место, пишете комментарий и выгружаете скриншот всей страницы со всеми маркерами и текстами.

## Установка

1. Распакуйте архив и переложите папку туда, где она будет лежать постоянно, например в
   «Документы». Chrome запускает расширение прямо из этой папки, поэтому после установки её
   нельзя удалять или перемещать.
2. Откройте в Chrome адрес `chrome://extensions` и включите **«Режим разработчика»**
   (переключатель справа вверху).
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `extension`.
4. Закрепите иконку на панели: значок пазла → булавка у «Comment My Site».

Так же расширение ставится в Edge, Brave, Arc и Яндекс.Браузер.

## Сохранение сразу на рабочий стол (macOS, по желанию)

Без этого шага при экспорте открывается окно «Сохранить как». Chrome запоминает выбранную
папку, так что рабочий стол достаточно выбрать один раз.

Чтобы картинки сохранялись на рабочий стол без вопросов:

1. Откройте «Терминал», напечатайте `bash` и пробел, перетащите в окно файл
   `native-host/install.sh` и нажмите Enter.
2. При первом экспорте macOS спросит, разрешить ли Chrome доступ к папке «Рабочий стол».
   Нужно разрешить.

Для установщика нужен python3. Если его нет, установщик подскажет, как его поставить.
Удаляется так же, только файл `native-host/uninstall.sh`.

## Как пользоваться

| Действие | Как |
|---|---|
| Оставить комментарий | иконка расширения или **⌥⇧C** (на Windows **Alt+Shift+C**): в центре экрана появится маркер |
| Поставить маркер | перетащите маркер (или заголовок карточки) на нужное место |
| Сохранить текст | **Enter** или «Готово» (**Shift+Enter** переносит строку) |
| Ещё один маркер | кнопка «Комментарий» на панели или клавиша **C** |
| Изменить или удалить | нажмите на маркер; при наведении видно текст |
| Экспорт | «Экспорт PNG»: снимок всей страницы с маркерами и комментариями |
| Очистить страницу | «Очистить» на панели, затем «Удалить все?» для подтверждения; 6 секунд можно нажать «Вернуть» |
| Переместить панель | потяните за ⋮⋮ слева; двойной клик возвращает панель на место |
| Скрыть | ✕ на панели (комментарии останутся) |

Комментарии хранятся только в вашем браузере, отдельно для каждой страницы. Коллегам
отправляйте готовый PNG.

## Ограничения

- Во время экспорта страница сама прокручивается несколько секунд, прогресс виден на иконке.
  Не переключайте вкладку, пока идёт съёмка.
- Если страница прокручивается не целиком, а внутри своего блока (так устроены многие
  веб-приложения), в снимок попадёт только видимая часть.
- Chrome не даёт расширениям работать на служебных страницах (`chrome://…`, Chrome Web Store)
  и в просмотрщике PDF.
