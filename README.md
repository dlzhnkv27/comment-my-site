# Comment My Site

Расширение для Chrome: комментарии к любой странице, как в Figma. Ставите маркер на нужное
место, пишете комментарий и выгружаете скриншот всей страницы со всеми маркерами и текстами.
По умолчанию картинка сохраняется на рабочий стол.

## Установка

1. Откройте `chrome://extensions`, включите **Режим разработчика** (переключатель справа вверху).
2. Нажмите **Загрузить распакованное расширение** и выберите папку `extension/`.
3. Закрепите иконку расширения на панели (значок пазла → булавка).
4. Чтобы файлы сохранялись прямо на рабочий стол, один раз запустите помощник:

   ```bash
   ./native-host/install.sh
   ```

   Без помощника расширение тоже работает, но при каждом экспорте открывает диалог «Сохранить
   как». Chrome запоминает последнюю папку: выберите рабочий стол один раз, и дальше будет
   достаточно нажать Enter.

   При первом экспорте macOS может спросить, разрешить ли Chrome доступ к папке «Рабочий стол».
   Нужно разрешить.

У расширения постоянный ID `oeemgooahcildochbglgakimkehigkde` (он задаётся ключом в
`manifest.json`), поэтому помощник продолжит работать, даже если папку проекта переместить.
После перемещения расширение нужно один раз загрузить в Chrome заново.

## Как пользоваться

| Действие | Как |
|---|---|
| Оставить комментарий | иконка расширения или **⌥⇧C**: в центре экрана появится маркер |
| Поставить маркер | перетащите маркер (или заголовок карточки) на нужное место |
| Сохранить текст | **Enter** или «Готово» (**Shift+Enter** переносит строку) |
| Ещё один маркер | кнопка «Комментарий» на панели или клавиша **C** |
| Изменить или удалить | нажмите на маркер; при наведении видно текст |
| Экспорт | «Экспорт PNG»: снимок всей страницы с маркерами и карточками комментариев |
| Переместить панель | потяните за ⋮⋮ слева; двойной клик возвращает панель на место |
| Скрыть | ✕ на панели (комментарии останутся) |

Комментарии хранятся локально (`chrome.storage.local`) отдельно для каждого адреса страницы.
Они появятся снова, если открыть расширение на той же странице.

## Как устроен экспорт

Расширение прокручивает страницу экран за экраном, снимает каждый экран через
`chrome.tabs.captureVisibleTab` и склеивает кадры на canvas. Маркеры и карточки
дорисовываются поверх готового снимка.

- Сначала страница один раз прокручивается целиком, чтобы подгрузились ленивые картинки и
  анимации, которые запускаются при прокрутке.
- Фиксированные элементы (шапка, чат, cookie-баннер) попадают только в первый кадр, иначе они
  повторялись бы на каждом экране. Sticky-элементы снимаются на своём месте в потоке страницы.
- Chrome разрешает не больше двух снимков в секунду, поэтому длинная страница снимается
  несколько секунд. Прогресс показывается на иконке расширения.
- Во время съёмки панель и маркеры скрыты, а прокрутка мышью и клавиатурой заблокирована.

### Ограничения

- Если страница прокручивается не целиком, а внутри своего контейнера (так устроены многие
  веб-приложения), в снимок попадёт только видимая часть, а маркеры не будут двигаться вместе
  с содержимым.
- Страницы длиннее 50 000 px обрезаются: это защита от бесконечных лент. Если снимок
  превышает лимит canvas (32 767 px по стороне), он уменьшается.
- Маркеры привязаны к координатам документа. Если вёрстка поменяется (другая ширина окна,
  изменения контента), маркеры могут сместиться.
- Chrome не даёт расширениям работать на `chrome://`-страницах, в Chrome Web Store и в
  просмотрщике PDF. На таких страницах на иконке появится ✕.

## Структура

```
extension/
  manifest.json     MV3-манифест
  background.js     service worker: внедрение UI, съёмка кадров, сохранение
  content.js        UI на странице (Shadow DOM), склейка скриншота, отрисовка маркеров
  offscreen.*       сборка PNG в blob: URL для chrome.downloads (без помощника)
  icons/
native-host/
  comment_my_site_host.py   помощник native messaging: пишет PNG в ~/Desktop
  install.sh / uninstall.sh
test/harness.html   стенд для разработки: content.js с заглушками chrome.*
test/e2e-page.html  страница для проверки настоящего расширения (fixed, sticky, анимация при прокрутке)
tools/make_icons.py генерация иконок
```

## Разработка

Стенд `test/harness.html` запускает `content.js` в обычной вкладке с подменённым `chrome.*`.
Заглушка `captureVisibleTab` рисует элементы страницы по их координатам и линейку с
координатой Y, поэтому на стенде видно, ровно ли склеились кадры и где оказались маркеры.

```bash
python3 -m http.server 8791
```

Потом откройте http://localhost:8791/test/harness.html. С параметром `?seed` на странице
сразу будет группа пересекающихся комментариев.

После правок в `extension/` нажмите ↻ у расширения в `chrome://extensions` и перезагрузите
вкладку.

Удалить помощник:

```bash
./native-host/uninstall.sh
```
