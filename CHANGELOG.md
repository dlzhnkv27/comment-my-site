# Изменения

## 1.1.0

- На панели появилась кнопка «Очистить»: удаляет все комментарии на текущей странице.
  Работает в два шага: нажатие, затем «Удалить все?» для подтверждения. После удаления 6 секунд
  можно нажать «Вернуть». Раньше эта функция пряталась за иконкой корзины, которая появлялась
  только при наличии комментариев.

## 1.0.0

- Первая версия: маркеры-комментарии как в Figma, экспорт скриншота всей страницы со всеми
  комментариями, сохранение на рабочий стол через помощник для macOS.
